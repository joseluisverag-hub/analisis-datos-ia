# Análisis de Datos + IA Aplicada

Proyecto de portafolio orientado a análisis de datos con Python, SQL y una capa de IA aplicada para generar insights de negocio.

## Objetivo
Construir un proyecto práctico y publicable en GitHub que demuestre capacidades de:
- limpieza y análisis de datos
- consultas SQL
- visualización
- uso de IA aplicada al análisis

## Estructura
- `data/`: datasets
- `notebooks/`: notebooks del análisis
- `src/`: scripts o app

## Entregables automatizados

Este proyecto incluye generación automática de:
- reporte ejecutivo en PDF
- presentación ejecutiva en PowerPoint

El flujo toma métricas y hallazgos desde el notebook, exporta un payload JSON y genera entregables listos para stakeholders no técnicos.
